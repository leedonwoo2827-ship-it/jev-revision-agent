# JEV 개정 에이전트 (law-errata-jev)

법령이 바뀌면 **우리 교재의 어느 문장을 고쳐야 하는지** 찾아 주는 에이전트입니다.

- 교재 PDF 전체를 넣으면 차례를 뽑아 장별 워크스페이스를 만듭니다.
- 장마다 **법령(구·신)** 또는 **신규 개정기본서 PDF**를 넣으면 판정 엔진(Codex 또는 Claude)이 개정사항을 판정합니다.
- 판정 결과로 **수정확률 / 유지확률 검토 내역**이 만들어집니다.
- 모든 장의 후보를 **④ 정오 판정**에서 책 전체로 한 번에 체크하고, **⑤ 정오표 받기**에서 엑셀 · PDF · 검토 HTML · 게시판 HTML 정오표를 **책 전체 한 번에** 받습니다.

판정은 **JEV** 방식입니다.
- **J**udge: 영향유형을 정합니다.
- **E**vidence: 교재, 구 조문, 신 조문(또는 개정기본서)을 그대로 인용합니다.
- **V**erdict: 수정확률과 수정문구 초안을 냅니다.

판정 엔진은 **Codex CLI**(ChatGPT 계정)와 **Claude CLI**(claude.ai 계정) 중에서 고릅니다. 둘 다 OAuth로 로그인해서 쓰고 API 키는 필요 없습니다. 기본은 Codex이고, Claude는 그 PC에 Claude CLI가 설치·로그인된 경우에만 씁니다.

> 이 저장소에는 **코드만** 올립니다. 교재·법령·판정 결과·반영 산출물은 `workspace/`에 쌓이며, `workspace/`는 `.gitignore`로 제외되어 있습니다.

## 설치와 실행

| 파일 | 하는 일 |
|---|---|
| `setup.bat` | 처음 한 번만 실행합니다. 가상환경과 패키지를 설치하고, Codex CLI가 없으면 설치합니다. 로그인이 안 되어 있으면 `codex login`을 실행하니, 브라우저가 열리면 ChatGPT 계정으로 로그인하세요. Claude는 따로 설치합니다(아래 「Claude도 쓰려면」). |
| `run.bat` | **JEV 개정 에이전트 콘솔**을 엽니다 (`http://localhost:8765`). 콘솔을 쓰는 동안 검은 창은 닫지 마세요. |

Python 3.10 이상과 Node.js가 먼저 설치되어 있어야 합니다.

**Claude도 쓰려면 (선택)**: Codex만 쓰는 PC는 건너뜁니다.
1. 명령 프롬프트에서 `npm install -g @anthropic-ai/claude-code`
2. 콘솔 왼쪽 아래 Claude 메뉴 → [로그인] → 브라우저에서 claude.ai 계정으로 로그인
3. 「판정 엔진」을 Claude 또는 자동으로 바꿉니다.

## 콘솔 사용 순서

왼쪽 레일은 **① 책 넣기 · 차례 → ② 장별 판정 → ③ 판정 결과 → ④ 정오 판정 → ⑤ 정오표 받기** 순서입니다. 장은 레일에 늘어놓지 않고 ② 대시보드에서 고릅니다. [차례 확정]을 누르면 ②로 넘어갑니다.

**＋ 새 책 넣기** (레일 맨 위 버튼)
- 지금 작업 전체를 `backup/<날짜시각>_<책이름>/`으로 옮기고 빈 상태에서 시작합니다.
- 지우지 않으므로, 책 화면의 **이전 책** 목록에서 [불러오기]로 되돌릴 수 있습니다.

### ① 책 넣기 · 차례

**① 교재 PDF 전체**
- 교재 PDF **전체**를 화면에 끌어다 놓습니다. 쪼개지 않아도 됩니다.
- 차례가 자동으로 추출됩니다. 순서대로 시도합니다.
  1. PDF 책갈피. 책갈피가 3개 미만이거나 `0_…부속`, `1_…내지`처럼 파일 이름뿐이면 쓰지 않습니다.
  2. 책 앞 차례 쪽(여러 쪽이어도 됨)과 본문의 `CHAPTER NN` 표지
  3. 둘 다 실패하면 [AI로 다시 뽑기]. 왼쪽 아래 판정 엔진(Codex · Claude)으로 읽습니다.

**② 이 책의 법령**: 장마다 비교할 법률·시행령·시행규칙과 책 기준 버전입니다.
- 자동으로 찾는 순서
  1. `[법령적용기준]` 쪽 (예: 중기법 책)
  2. 그런 쪽이 없으면, 책에 실린 **법령 원문 머리글** `[시행 …] [법률 제N호, …]` (예: 경비업법 책 08장 '관련법령')
- 직접 넣기: 법령 이름을 넣고 [＋ 추가]를 누릅니다. "시행령·시행규칙도 함께"를 켜 두면 3개가 한꺼번에 들어갑니다.
- 책 기준 버전(공포번호,공포일@시행일)을 모르면 비워 둘 수 있습니다. 그 법령은 현행만 받고 비교에서 빠집니다. 구판 파일을 장 화면 구 칸에 직접 넣으면 함께 비교합니다.
- 책에 나오는 다른 법령(「…법」 · 「…법률」 · 「…령」 · 「…규칙」)이 언급 횟수와 함께 제안됩니다. 누르면 목록에 추가됩니다. 예: 「대통령 등의 경호에 관한 법률」.
- **[저장하고 장마다 법령 다시 연결]**을 누르면 장마다 기본 연결을 다시 정합니다.
  - 장 제목이 법령명과 같으면 그 법령 묶음을 연결합니다.
  - '관련법령' 장에는 책에 원문이 실린 법령을 연결합니다.
  - 기출·모의 장에는 목록의 법령을 **전부** 연결합니다. 기출은 「경비업법령상」처럼 법·시행령·시행규칙을 묶어 묻고 다른 법률도 나오기 때문입니다.
    - 기출 장은 판정 기준이 다릅니다. 문제·보기 문장은 시험 당시 법 기준이라 고치지 않고, 개정으로 정답·보기의 옳고 그름·해설이 달라지는 곳만 찾아 해설 끝에 「(법 개정으로 현재는 …)」 주석을 붙이는 수정안을 냅니다.
  - 나머지 장에는 책 이름에 들어 있는 주 법령을 연결합니다.
- **[법제처에서 현행 모두 받기]**를 누르면 현행과 책 기준판을 `workspace/00_책/법령/`에 한꺼번에 받습니다. 장 화면의 [법제처에서 구·신 법령 받기]는 여기 받아 둔 파일을 복사해 씁니다.

**③ 차례 확인**
- 포함 여부, 번호, 제목, 시작·끝 쪽(PDF 쪽 기준)을 고칩니다.
- **연결 법령** 칩을 눌러 장마다 켜고 끕니다. 모두 끄면 그 장은 개정기본서 대조로 진행합니다.
- 행 오른쪽 ＋/✕로 장을 나누거나 지웁니다.
- **[차례 확정]**을 누르면 장별 워크스페이스가 만들어지고 ② 장별 판정으로 안내합니다.
- 이미 판정한 뒤에 [차례 확정]을 다시 눌러도 됩니다. 연결 법령이 그대로인 장은 비교 방식 · 판정 결과 · ④ 체크가 그대로 남고, 연결 법령이 바뀐 장만 비교 방식을 다시 정합니다.

**기출 장을 법령으로 대조하기 (예: 경비지도사 2차 경비업법 책 09 기출문제)**

기출은 「경비업법령상 …」처럼 법·시행령·시행규칙을 묶어 묻고, 조문 번호 없이 「대통령 등의 경호에 관한 법률」 같은 다른 법률도 끌어옵니다. 그래서 기출 장에는 책의 법령을 **전부** 연결해 법령 비교로 판정합니다. 바뀐 조문마다 기출 장 전체를 읽혀서, 조문 번호가 없는 문제도 내용으로 찾습니다.

경비업법·청원경찰법(법·시행령·시행규칙)만 비교한다면 0~3단계는 건너뛰고 4단계부터 하면 됩니다.

0. **run.bat을 다시 켭니다.** 코드가 바뀌었으면 꼭 다시 켜야 합니다. 일괄 작업이 도는 중이면 끝난 뒤에 켜세요.
1. **(다른 법률도 비교하려면) ① 책 넣기 · 차례 → ② 이 책의 법령**
   - 아래 「책에 나오는 다른 법령 (언급 횟수)」에서 법률을 눌러 추가합니다. 예: `＋ 대통령 등의 경호에 관한 법률 9`. 이렇게 누르면 그 법률 하나만 들어갑니다.
   - 시행령도 비교하려면 위 입력칸에 `대통령 등의 경호에 관한 법률 시행령`을 넣고 「시행령·시행규칙도 함께」를 **끈 채** [＋ 추가]를 누릅니다.
     - 「함께」를 켜 두면 없는 시행규칙까지 들어갑니다. 경호법은 시행규칙이 없습니다.
     - 그래도 문제는 없습니다. 받기에 실패한 그 칸만 빠지고 나머지는 계속 받습니다. 거슬리면 ✕로 빼세요.
   - 결격사유처럼 「…법을 위반하여」로 이름만 인용되는 법률은 넣지 않아도 됩니다. 정답을 정하는 건 경비업법·청원경찰법 쪽입니다.
2. **책 기준 버전 칸을 채웁니다.** 이게 빠지면 그 법령은 비교되지 않습니다.
   - 비교는 「책 기준(구)판 ↔ 현행」의 차이로 합니다. 그래서 새로 넣은 법률도 책 기준 버전을 알아야 비교됩니다.
   - 비워 두면 현행만 받고 비교에서는 뺍니다. ② 대시보드 ▸ 펼침에 「버전 모름 · 비교 안 함」으로 보이고, 장 판정은 나머지 법령으로 그대로 진행합니다.
   - 찾는 법
     1. 법제처(law.go.kr)에서 그 법령을 열고 왼쪽 **연혁**을 엽니다.
     2. 책 기준일 무렵 시행 중이던 판을 고릅니다. 책 기준일은 목록에 있는 다른 법령의 버전을 보면 됩니다. 이 책은 경비업법 2025. 1. 31. 시행판 기준입니다.
     3. 그 판 머리글 `[법률 제20000호, 2024. 12. 3., 일부개정]`의 번호와 날짜를 `20000, 2024.12.3`처럼 적습니다.
3. **[저장하고 장마다 법령 다시 연결]**을 누릅니다. 기출·모의 장에는 목록의 법령이 전부 붙고, 나머지 장은 지금 연결 그대로입니다(관련법령 장은 책에 원문이 실린 법령만).
4. **③ 차례 확인**에서 기출 행의 연결 법령 칩이 모두 켜졌는지 보고 **[차례 확정]**을 누릅니다.
   - 기출 장이 「기본서 대조」에서 「법령 비교」로 바뀝니다.
   - 다른 장의 판정 결과와 ④ 체크는 그대로 남습니다.
5. **② 장별 판정**에서 기출 장만 체크하고 **▶ 1→2 받고 판정**을 누릅니다.
   - 현행과 책 기준판을 법제처에서 자동으로 받으니, ①의 [법제처에서 현행 모두 받기]는 따로 누르지 않아도 됩니다.
   - 호출 수는 연결 법령에서 바뀐 조문 수만큼입니다. 장 하나 판정과 비슷합니다.
6. **④ 정오 판정**: 기출 장 탭에서 확인합니다. 기출 장은 판정 기준이 다릅니다.
   - 문제·보기 문장은 시험 당시 법 기준이라 고치는 안을 내지 않습니다.
   - 개정으로 정답, 보기의 옳고 그름, 해설이 달라지는 곳만 나옵니다.
   - 수정안은 해설(해설이 없으면 그 문제의 마지막 보기) 끝에 「(법 개정으로 현재는 …)」 주석을 붙인 형태입니다. 사유 칸에 시험 당시 정답과 현행 기준 정답이 함께 적힙니다.
   - 장 제목에 「기출」이나 「모의」가 들어 있으면 기출 장으로 봅니다.

**판정 엔진 (왼쪽 아래 · ② 아래 「엔진 · 사용 한도」)**
- **Codex (ChatGPT)** · **자동 (Codex 먼저, 한도면 Claude)** · **Claude** 중에서 고릅니다. 설정은 그 PC에만 저장됩니다(`_settings.json`, git 제외). 담당자 PC는 손대지 않으면 Codex로 돕니다.
- **한도면 최대 N시간 기다렸다가 이어서**: ② 일괄 작업 중 사용 한도에 걸리면 이 시간까지 기다렸다가 같은 장부터 다시 합니다(0 = 바로 멈춤). 기다리는 동안 콘솔 창(run.bat)은 켜 두세요. PC 절전은 막습니다.
- 판정이 끝난 조문은 장의 `03_판정/cache/`에 하나씩 저장됩니다. 엔진을 바꾸거나 멈췄다가 다시 눌러도 끝난 조문은 다시 부르지 않고 이어서 합니다.
- Claude 모델은 기본 `sonnet`입니다. 바꾸려면 환경변수 `JEV_CLAUDE_MODEL`을 지정하세요.

**Codex · Claude 계정 (왼쪽 아래)**
- 레일 맨 아래에 Codex · Claude 상태와 로그인한 계정이 보입니다. 누르면 메뉴가 열립니다. 아래는 Codex 메뉴 설명이고, Claude 메뉴도 같습니다(로그인 `claude auth login --claudeai`, 로그아웃 `claude auth logout`). Claude CLI가 없는 PC는 「Claude 없음」으로만 보이고 판정에는 영향이 없습니다.
  - 🟢 정상
  - 🟡 확인 필요
  - 🔴 로그인 필요 / 만료
- **[새로고침]**: 로그인 상태를 확인하고, Codex를 실제로 한 번 짧게 불러 봅니다(10~30초). `codex login status`가 "Logged in"이라고 해도 토큰이 서버에서 폐기됐을 수 있어서, 실제로 불러 봐야 확실합니다.
- **[로그인]**: 기존 로그인을 해제하고 새 창에서 `codex login`을 실행합니다. 브라우저가 열리면 ChatGPT 계정으로 로그인하세요. 끝나면 자동으로 다시 확인합니다.
- **[로그아웃]**: `codex logout`을 실행합니다.
- 판정이나 차례 뽑기 중에 `Failed to refresh token`, `401`, `sign in again` 오류가 나면 빨간 안내와 **[Codex 다시 로그인]** 버튼이 뜹니다. Claude 로그인이 만료되면 **[Claude 다시 로그인]**이 뜹니다.
- 사용 한도에 걸리면 안내가 뜹니다. 엔진을 바꾸고 다시 누르면 끝난 조문 다음부터 이어서 합니다.
- 콘솔 밖에서 다시 로그인하려면 `codex-다시로그인.bat`을 더블클릭하세요.

### ② 장별 판정

대시보드입니다. 장마다 한 줄로 **1 비교 자료 · 2 판정 · 3 후보·권고 · 4 체크 · 5 정오표** 현황을 보고, 고른 장에 단계를 실행합니다.

- 행 왼쪽 ▸를 누르면 그 장에 연결된 법령마다 **책 기준(구) · 현행(신)** 파일 상태가 아래 줄로 펼쳐집니다.
- 장을 체크하고 버튼을 누르면 고른 장에만 차례로 합니다. 장이 많으면 나눠 골라 시간대를 갈라 돌려도 됩니다.
  - **1 최근 법령 받기**: 법제처에서 현행을 새로 받습니다(같은 법령은 한 번만). 책 기준(구)판은 받아 둔 것을 씁니다.
  - **2 판정**: 비어 있는 법령 칸을 자동으로 채운 뒤 판정합니다. 이미 판정한 장은 건너뜁니다. 다시 하려면 「판정한 장도 다시 판정」을 켜세요(그 장의 ④ 체크는 기본값으로 돌아갑니다).
  - **▶ 1→2**: 받고 바로 판정합니다.
  - **■ 멈춤**: 진행 중인 호출(최대 3개)만 끝내 저장하고 바로 멈춥니다. 다시 누르면 끝난 조문 다음부터 합니다. 장 화면의 판정에도 같은 버튼이 있습니다.
- 위쪽에 Codex · Claude 계정과 지금 엔진이 한 줄로 보입니다. 한도를 기다리는 중이면 그 장 행에 「⏸ 한도 대기 HH:MM」이 뜹니다.
- 자료가 모자란 장은 건너뛰고 끝에 알려 줍니다. 「4 체크」를 누르면 ④에서 그 장이 열리고, 「5 정오표」가 「다시 만들기」면 ⑤에서 다시 만드세요.
- 제목을 누르면 아래 **장 화면**이 열립니다.

### 장 화면 (② 표에서 장 제목 선택)

**1. 비교 자료**: 두 방식 중 하나를 고릅니다.

- **법령 구·신 비교**
  - 연결된 법령마다 책 기준·현행 칸이 생깁니다. 예를 들어 법률·시행령·시행규칙이면 6칸입니다. 이 칸에 파일을 끌어다 놓습니다.
  - 여러 파일을 카드에 한꺼번에 놓아도 됩니다. 법제처 저장 파일명에 들어 있는 법령번호로 칸을 자동으로 찾아 넣습니다.
  - **[법제처에서 구·신 법령 받기]**를 누르면 자동으로 받아 옵니다.
- **신규 개정기본서 대조**
  - 최신 기본서 PDF를 넣습니다. 같은 제목의 장을 찾아 쪽 범위를 자동으로 잡습니다.
  - 우리 책을 4쪽씩 나눠 기본서와 대조합니다.

파일 형식은 PDF를 권장합니다. HWPX와 TXT도 받습니다. HWP(구형)는 받지 않습니다.

**2. 판정 시작**
- 진행률과 로그가 실시간으로 표시됩니다.
- 법령 비교는 바뀐 조문마다, 기본서 대조는 구간마다 판정 엔진을 한 번씩 호출합니다. 로그에 `[Codex]` / `[Claude]`로 어느 엔진이 판정했는지 나옵니다.
- 실행 중이면 옆에 **[■ 멈춤]**이 있습니다.
- 이미 판정한 단위는 캐시를 써서 다시 호출하지 않습니다.

**3. 판정 결과**
- 법령 버전과 후보 · 수정 권고 건수를 보여 줍니다. [④ 정오 판정에서 이 장 체크하기]로 넘어갑니다.

### ③ 판정 결과

- 판정한 장 전체의 합계(바뀐 조문 · 후보 · 수정 권고 · 실패)와 장별 표입니다.

### ④ 정오 판정 (책 전체)

- 모든 장의 수정 후보가 한 목록에 나옵니다. 위쪽 탭(전체 / 08장 / 09장 …)으로 장을 골라 볼 수 있습니다.
- 수정확률 60% 이상은 처음부터 체크되어 있습니다. 확률 필터 기본값은 20% 이상(유지 숨김)입니다.
- 항목마다 기존 → 수정(바뀐 글자만 붉게/녹색), 사유, [근거 보기](교재 · 구 조문 · 신 조문), 수정 문구 고치기, 메모가 있습니다. 체크는 바로 저장됩니다.
- **[정오표 만들기]**를 누르면 ⑤로 넘어갑니다. 여기서 고친 수정 문구 · 메모가 정오표에 들어갑니다.
- **[체크본 가져오기]**: 「정오표_검토.html」에서 저장한 `.json`이나, 「전체 후보」 시트를 고친 정오표 `.xlsx`를 올리면 수정 문구 · 메모가 그대로 들어옵니다.

### ⑤ 정오표 받기 (책 전체 한 번에)

`workspace/_정오표/`에 **수정확률 5단계마다 한 벌씩** 만들어집니다. 화면에도 5줄로 펼쳐 나옵니다.

- 단계: 확률 전체 · 20% 이상 · 40% 이상 · 60% 이상 · 80% 이상 (④ 확률 필터와 같은 단계)
- 한 줄의 파일에는 그 단계 이상인 후보가 **모두** 같은 건수로 들어갑니다(④ 체크와 상관없음). 고칠 글자가 없는 '유지' 줄은 엑셀 「확인」 칸에 「고칠 글자 없음(유지)」로 표시됩니다.

| 파일 (`<단계>` = 전체 · 20이상 · 40이상 · 60이상 · 80이상) | 용도 |
|---|---|
| `<책>_<단계>_정오표.xlsx` | 저자에게 보내기. [정오표] 그 단계 후보 · [전체 후보] 후보 전부 · [요약] 장별 건수와 법령 버전. 원고에서 위치를 못 찾은 줄은 「확인」 칸에 표시 |
| `<책>_<단계>_정오표_검토.pdf` | 인쇄해서 회의 (☑/☐ 체크칸 · 메모칸) |
| `<책>_<단계>_정오표_검토.html` | 브라우저에서 같이 보며 수정 문구 · 메모를 고친 뒤 [체크 결과 저장] → ④ 「체크본 가져오기」 |
| `<책>_<단계>_정오표_게시판.html` | 회사 게시판용. 장마다 표 하나 + 법령 구·신 버전 |
| [이 줄 한 번에 받기] | 그 줄 파일 모두 zip 하나 |

④에서 고친 뒤 파일을 다시 만들지 않았으면 경고와 [다시 만들기] 버튼이 뜹니다.
