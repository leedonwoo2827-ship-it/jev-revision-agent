# JEV 개정 에이전트 (law-errata-jev)

법령이 바뀌면 **우리 교재의 어느 문장을 고쳐야 하는지** 찾아 주는 에이전트입니다.

- 교재 PDF 전체를 넣으면 차례를 뽑아 장별 워크스페이스를 만듭니다.
- 장마다 **법령(구·신)** 또는 **신규 개정기본서 PDF**를 넣으면 Codex가 개정사항을 판정합니다.
- 판정 결과로 **수정확률 / 유지확률 검토 내역**이 만들어집니다.
- 검토 화면에서 체크하고 [반영]을 누르면 반영내역, 반영된 원고, 게시판용 정오표가 나옵니다.

판정은 **JEV** 방식입니다.
- **J**udge: 영향유형을 정합니다.
- **E**vidence: 교재, 구 조문, 신 조문(또는 개정기본서)을 그대로 인용합니다.
- **V**erdict: 수정확률과 수정문구 초안을 냅니다.

판정 엔진은 **Codex CLI**이고, ChatGPT 계정 OAuth로 로그인해서 씁니다. API 키는 필요 없습니다.

> 이 저장소에는 **코드만** 올립니다. 교재·법령·판정 결과·반영 산출물은 `workspace/`에 쌓이며, `workspace/`는 `.gitignore`로 제외되어 있습니다.

## 설치와 실행

| 파일 | 하는 일 |
|---|---|
| `setup.bat` | 처음 한 번만 실행합니다. 가상환경과 패키지를 설치하고, Codex CLI가 없으면 설치합니다. 로그인이 안 되어 있으면 `codex login`을 실행하니, 브라우저가 열리면 ChatGPT 계정으로 로그인하세요. |
| `run.bat` | **JEV 개정 에이전트 콘솔**을 엽니다 (`http://127.0.0.1:8765`). 콘솔을 쓰는 동안 검은 창은 닫지 마세요. |

Python 3.10 이상과 Node.js가 먼저 설치되어 있어야 합니다.

## 콘솔 사용 순서

왼쪽 레일 맨 위가 **0 책 넣기 · 차례**이고, 그 아래로 장 목록이 이어집니다.

**＋ 새 책 넣기** (레일 맨 위 버튼)
- 지금 작업 전체를 `backup/<날짜시각>_<책이름>/`으로 옮기고 빈 상태에서 시작합니다.
- 지우지 않으므로, 책 화면의 **이전 책** 목록에서 [불러오기]로 되돌릴 수 있습니다.

### 0. 책 넣기 · 차례

**① 교재 PDF 전체**
- 교재 PDF **전체**를 화면에 끌어다 놓습니다. 쪼개지 않아도 됩니다.
- 차례가 자동으로 추출됩니다. 순서대로 시도합니다.
  1. PDF 책갈피. 책갈피가 3개 미만이거나 `0_…부속`, `1_…내지`처럼 파일 이름뿐이면 쓰지 않습니다.
  2. 책 앞 차례 쪽(여러 쪽이어도 됨)과 본문의 `CHAPTER NN` 표지
  3. 둘 다 실패하면 [Codex로 다시 뽑기]. 이 PC에 Codex 로그인이 되어 있어야 합니다.

**② 이 책의 법령**: 장마다 비교할 법률·시행령·시행규칙과 책 기준 버전입니다.
- 자동으로 찾는 순서
  1. `[법령적용기준]` 쪽 (예: 중기법 책)
  2. 그런 쪽이 없으면, 책에 실린 **법령 원문 머리글** `[시행 …] [법률 제N호, …]` (예: 경비업법 책 08장 '관련법령')
- 직접 넣기: 법령 이름을 넣고 [＋ 추가]를 누릅니다. "시행령·시행규칙도 함께"를 켜 두면 3개가 한꺼번에 들어갑니다.
- 책 기준 버전(공포번호,공포일@시행일)을 모르면 비워 둡니다. 그러면 구판은 장 화면에서 직접 넣습니다.
- 책에 나오는 다른 법령(「…법」)이 언급 횟수와 함께 제안됩니다. 누르면 목록에 추가됩니다.
- **[저장하고 장마다 법령 다시 연결]**을 누르면 장마다 기본 연결을 다시 정합니다.
  - 장 제목이 법령명과 같으면 그 법령 묶음을 연결합니다.
  - '관련법령' 장에는 전체를 연결합니다.
  - 기출 장에는 연결하지 않습니다.
  - 나머지 장에는 책 이름에 들어 있는 주 법령을 연결합니다.
- **[법제처에서 현행 모두 받기]**를 누르면 현행과 책 기준판을 `workspace/00_책/법령/`에 한꺼번에 받습니다. 장 화면의 [법제처에서 구·신 법령 받기]는 여기 받아 둔 파일을 복사해 씁니다.

**③ 차례 확인**
- 포함 여부, 번호, 제목, 시작·끝 쪽(PDF 쪽 기준)을 고칩니다.
- **연결 법령** 칩을 눌러 장마다 켜고 끕니다. 모두 끄면 그 장은 개정기본서 대조로 진행합니다.
- 행 오른쪽 ＋/✕로 장을 나누거나 지웁니다.
- **[차례 확정]**을 누르면 장별 워크스페이스가 만들어집니다.

**Codex 계정 (왼쪽 아래)**
- 레일 맨 아래에 Codex 상태와 로그인한 계정이 보입니다. 누르면 메뉴가 열립니다.
  - 🟢 정상
  - 🟡 확인 필요
  - 🔴 로그인 필요 / 만료
- **[새로고침]**: 로그인 상태를 확인하고, Codex를 실제로 한 번 짧게 불러 봅니다(10~30초). `codex login status`가 "Logged in"이라고 해도 토큰이 서버에서 폐기됐을 수 있어서, 실제로 불러 봐야 확실합니다.
- **[로그인]**: 기존 로그인을 해제하고 새 창에서 `codex login`을 실행합니다. 브라우저가 열리면 ChatGPT 계정으로 로그인하세요. 끝나면 자동으로 다시 확인합니다.
- **[로그아웃]**: `codex logout`을 실행합니다.
- 판정이나 차례 뽑기 중에 `Failed to refresh token`, `401`, `sign in again` 오류가 나면 빨간 안내와 **[Codex 다시 로그인]** 버튼이 뜹니다.
- 콘솔 밖에서 다시 로그인하려면 `codex-다시로그인.bat`을 더블클릭하세요.

### 장 화면 (레일에서 장 선택)

**1. 비교 자료**: 두 방식 중 하나를 고릅니다.

- **법령 구·신 비교**
  - 연결된 법령마다 책 기준·현행 칸이 생깁니다. 예를 들어 법률·시행령·시행규칙이면 6칸입니다. 이 칸에 파일을 끌어다 놓습니다.
  - 여러 파일을 카드에 한꺼번에 놓아도 됩니다. 법제처 저장 파일명에 들어 있는 법령번호로 칸을 자동으로 찾아 넣습니다.
  - **[법제처에서 구·신 법령 받기]**를 누르면 자동으로 받아 옵니다.
- **신규 개정기본서 대조**
  - 최신 기본서 PDF를 넣습니다. 같은 제목의 장을 찾아 쪽 범위를 자동으로 잡습니다.
  - 우리 책을 4쪽씩 나눠 기본서와 대조합니다.

파일 형식은 PDF를 권장합니다. HWPX와 TXT도 받습니다. HWP(구형)는 받지 않습니다.

**2. 판정 시작**
- 진행률과 로그가 실시간으로 표시됩니다.
- 법령 비교는 바뀐 조문마다, 기본서 대조는 구간마다 Codex를 한 번씩 호출합니다.
- 이미 판정한 단위는 캐시를 써서 다시 호출하지 않습니다.

**3. 검토 내역**
- 화면 안에서 바로 보입니다.
- 수정확률 60% 이상인 항목은 처음부터 체크되어 있고, 유지 항목은 기본으로 숨겨져 있습니다.
- 수정문구를 고치고 메모를 남긴 뒤 **[반영]**을 누릅니다.

**4. 반영 파일**
- 만들어진 파일을 보거나 내려받습니다.
- 회사 게시판에는 **`정오표_게시판_*.html`**을 올리세요.

## 워크스페이스 (장별, 단계별 번호 폴더)

```
workspace/
  00_책/                       교재 원본 PDF, toc.json (확정 차례 · 법령적용기준)
  09_소상공인기본법/
    chapter.json               쪽 범위 · 비교 방식 · 연결 법령
    00_원고/                   장 추출본 (ch09.pdf, ch09.txt, book.json)
    01_비교자료/               법령 구·신 / 개정기본서
    02_변경목록/               changes.json (바뀐 조문 또는 대조 구간)
    03_판정/                   results.json, cache/ (Codex JEV 판정)
    04_검토/                   검토_ch09.html
    05_반영/                   반영내역_*.md/.csv · ch09_revised_*.md/.html · 정오표_게시판_*.html
  10_소상공인_보호_및_지원에_관한_법률/
  ...
```

장 화면 위쪽의 단계 칸을 누르면 해당 폴더가 탐색기에서 열립니다. 워크스페이스 위치는 환경변수 `JEV_WORKSPACE`로 바꿀 수 있습니다.

## 명령줄 (선택)

```
.venv\Scripts\python -m jev.pipeline --toc        # workspace/00_책 의 PDF로 차례 확정
.venv\Scripts\python -m jev.fetch_law 09          # 09장 법령 구·신 받기
.venv\Scripts\python -m jev.pipeline 09           # 09장 판정
.venv\Scripts\python -m jev.apply decisions_ch09.json   # 서버 없이 받은 결정 파일 반영
```

## 구성

```
setup.bat / run.bat
jev/config.py         워크스페이스 · 장 설정
jev/toc.py            교재 차례 · 법령적용기준 추출 (+ Codex 대안)
jev/extract_book.py   장 원고 추출
jev/extract_law.py    법령 PDF/HWPX/TXT → 조문·장 단위 파싱
jev/diff_law.py       법령 구·신 비교 / 개정기본서 대조 구간 생성
jev/fetch_law.py      법제처 본문 받기
jev/judge_codex.py    codex exec --output-schema 로 JEV 판정, 중복 정리, 캐시
jev/report.py         검토 내역 HTML
jev/apply.py          반영 (반영내역 / 반영본 / 게시판 정오표)
jev/server.py         콘솔 서버 (127.0.0.1 전용)
jev/console.html      콘솔 화면 (레일 UI, 드래그 앤 드롭)
```

## 주의

- 확률은 Codex가 판단한 값입니다. 최종 반영 여부는 반드시 사람이 확인하세요.
- 수정 위치는 교재 텍스트에서 공백을 무시하고 찾습니다. 위치를 찾지 못한 항목은 반영내역에 "수동반영 필요"로 표시됩니다.
